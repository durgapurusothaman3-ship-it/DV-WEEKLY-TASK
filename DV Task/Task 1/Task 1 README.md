# Task 1 – SuperStore Data Analysis

## About the Project

This project analyzes the SuperStore dataset using Python. The main focus is to explore the data, calculate delivery time, and study sales based on product categories.

## Objectives

- Explore the SuperStore dataset.
- Understand the dataset structure.
- Calculate delivery days.
- Check missing values.
- Analyze category-wise sales.
- Create simple data visualizations.

## Process

1. Load the SuperStore dataset.
2. Display and inspect the data.
3. Convert Order Date and Ship Date into date format.
4. Calculate Delivery Days.
5. Identify product categories.
6. Check missing values.
7. Calculate total sales for each category.
8. Visualize category-wise sales.
9. Analyze sales distribution.

## Visualizations

- **Sales by Category:** Bar chart showing total sales for each category.
- **Sales Distribution:** Histogram showing the distribution of sales amounts.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Conclusion

The project provides a simple analysis of the SuperStore dataset. It helps understand delivery time, category-wise sales, missing values, and sales distribution through Python-based data analysis and visualization.
