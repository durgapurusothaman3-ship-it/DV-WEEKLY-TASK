# House Price Visualization & Spatial Analytics

## Overview
This project analyzes real estate data using Python to understand house price patterns, property features, and geographical variations.

## Objectives
- Visualize living area vs. house price using regression plots.
- Compare prices across property grades and waterfront status.
- Create geographical price visualizations using latitude and longitude.
- Identify high-value locations using ZIP code analysis.
- Generate a real estate investment summary.

## Dataset
`kc_house_data_processed.csv`

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab.

## Conclusion
This project helps identify house price patterns and high-value locations through data visualization and spatial analysis.
