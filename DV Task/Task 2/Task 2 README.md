# Week 2 – SuperStore Data Analysis

## Project Overview

This project focuses on analyzing the SuperStore dataset using Python. 
The main purpose is to understand sales, profit, discount, and category-wise performance through data analysis and visualization.

## Objectives

- Load and explore the SuperStore dataset.
- Analyze the structure and statistics of the data.
- Calculate delivery days.
- Check for missing values.
- Analyze sales by category.
- Analyze profit by category.
- Study the relationship between discount and profit.
- Find correlations between numerical columns.

## Data Analysis

The project includes:

- Data loading using Pandas.
- Data exploration using `head()`, `info()`, and `describe()`.
- Conversion of Order Date and Ship Date.
- Calculation of Delivery Days.
- Missing value checking.
- Category-wise sales analysis.
- Profit analysis.
- Discount and profit analysis.
- Correlation analysis.

## Visualizations

The following visualizations are created:

- Sales by Category – Bar Plot
- Sales Distribution – Histogram
- Profit by Category – Bar Plot
- Sales Distribution by Category – Bar Plot
- Profit Distribution – Box Plot
- Profit Variation Across Categories – Box Plot
- Impact of Discount on Profit – Scatter Plot
- Correlation Heatmap
