# Real Estate Valuation Analysis

## Overview
This project uses Python to analyze real estate data, calculate price per square foot, and identify extreme property valuation outliers.

## Objectives
- Clean missing and invalid data.
- Calculate property age and renovation status.
- Analyze price per square foot.
- Detect outliers using box plots and IQR statistical bounds.
- Visualize property price patterns.

## Tools Used
Python
Pandas 
NumPy
Matplotlib
Seaborn
Google Colab.

## Dataset
`kc_house_data.csv` — contains house prices and property features.

## Conclusion
This project helps analyze property values and identify unusual prices using statistical methods and data visualization.
